# 대화 세션 기록

다른 컴퓨터에서 같은 맥락으로 이어서 작업하기 위한 Claude Code 트랜스크립트.

| 파일 | 날짜 | 내용 |
|---|---|---|
| `88287ba7-b605-4a25-b997-614a3abb5c85.jsonl` | 2026-09-03 | iPhone 16 Pro Max 웹 프리뷰 셸 구축 → seed 토큰/컴포넌트를 Figma로 옮기는 익스포트 파이프라인 제작 |

## 다른 컴퓨터에서 이어받기

Claude Code는 세션을 `~/.claude/projects/<경로의 / 를 - 로 바꾼 이름>/` 아래에서 찾는다.
저장소를 클론한 뒤 프로젝트 폴더에서:

```bash
mkdir -p ~/.claude/projects/$(pwd | sed 's/\//-/g') && cp .claude/sessions/*.jsonl "$_" && claude --resume
```

`--resume` 목록에서 위 세션을 고르면 된다. 트랜스크립트 안의 절대 경로(`/Users/littleduck/...`)는
기록 당시 값이라 컴퓨터가 다르면 맞지 않는다. 파일 참조는 저장소 기준 상대 경로로 다시 확인할 것.

## 이 세션에서 정해진 것

- 프리뷰는 실제 로직 px(440×956) 그대로 그리고, 뷰포트에 맞춰 `--device-scale`로만 축소한다.
- seed 위에 별칭 토큰 레이어를 만들지 않는다. 앱 레이어에는 seed에 없는 것(화면 골격, 기기 프레임)만 둔다.
- Figma 쪽 진실의 원천은 `node_modules/@seed-design/css`다. 손으로 그리지 않고
  `npm run figma:export`로 뽑아 플러그인이 그린다. seed 버전을 올리면 다시 export 한다.
- 컴포넌트 자동 생성은 루트 프레임 + 라벨 구조인 것만 대상으로 한다 (`figma-plugin/README.md` 참고).

## 주의

- 이 파일들은 대화 전문이다. 저장소가 공개되어 있으므로 이후 세션을 추가할 때는
  자격증명이나 비공개 정보가 섞이지 않았는지 확인하고 넣을 것.
- 트랜스크립트는 복사 시점까지만 기록돼 있어 마지막 몇 턴은 빠져 있을 수 있다.
